# أثير القرآن

تطبيق ويب ثابت للاستماع إلى إذاعات القرآن الكريم وتصفح مكتبة التلاوات وتنزيل السور للاستماع دون اتصال. التطبيق لا يحتوي على خادم خاص أو حسابات مستخدمين؛ تُحمّل بيانات الإذاعات والقراء من واجهة `mp3quran.net`، ويُطلب صوت الإذاعة مباشرة من مزود البث.

## المتطلبات والتشغيل

يتطلب Node.js `^20.19.0` أو `>=22.12.0` وnpm. يعتمد البناء على Vite 8؛ خرائط المصدر معطلة في بناء الإنتاج.

```bash
npm ci
npm start
```

يفتح خادم التطوير على `http://localhost:5173`. الأوامر المتاحة:

```bash
npm run dev      # خادم التطوير
npm run build    # بناء نسخة الإنتاج في dist
npm run preview  # معاينة نسخة الإنتاج
npm test         # اختبارات الوحدات باستخدام Node.js
```

## البنية

- `index.html`: نقطة دخول HTML، واتجاه RTL، والبيانات الوصفية.
- `app.js`: عرض الصفحات، تفاعل المستخدم، حالة المشغل، وتنسيق استخدام الخدمات.
- `src/audio/radio-recovery.js`: استعادة بث الراديو بعد الانقطاع بتأخير تصاعدي محدود.
- `styles.css`: التصميم المتجاوب، الألوان، حالات الواجهة والحركة.
- `public/sw.js`: يخزن ملفات CSS/JavaScript التي يشير إليها HTML المبني من Vite وملفات التطبيق الأخرى، ويعيد الواجهة عند انقطاع الشبكة؛ لا يخزن طلبات واجهات الطرف الثالث أو ملفات الصوت.
- `tests/`: اختبارات الوحدات.

## الصوت والخصوصية والتخزين

- إذا توقّف تدفق الراديو أو انتهى، ينتظر التطبيق فترة قصيرة ثم يعيد الاتصال تلقائيًا. تزداد الفواصل بين محاولات الفشل تدريجيًا حتى حد أقصى قدره دقيقة. عند منع المتصفح التشغيل التلقائي، ينتظر التطبيق تفاعلًا من المستخدم بدلًا من تكرار المحاولات.
- لا يحفظ التطبيق موضعًا أو سجلًا للراديو، ولا يطلب بث الراديو عبر واجهة التنزيلات. لا يعترض `Service Worker` الطلبات الخارجية أو طلبات الصوت. قد يعتمد التخزين المؤقت المؤقت داخل المتصفح أو شبكة التوصيل على سياسات المتصفح ومزود البث، وليس على تخزين التطبيق.
- حفظ سورة للاستماع دون اتصال إجراء اختياري وصريح؛ تحفظ الملفات التي يختارها المستخدم فقط في `IndexedDB`.
- أزيلت خاصية تثبيت التطبيق وإشارات `PWA` من الواجهة. يبقى `Service Worker` لدعم فتح الواجهة دون اتصال، ويعرض الموقع تنبيهًا ويوجه المستخدم إلى تنزيلاته عند انقطاع الشبكة.
- إعدادات المظهر والصوت والمفضلة وتقدم السور تحفظ محليًا في `localStorage`. تعذر الوصول إلى التخزين المحلي لا ينبغي أن يمنع عرض التطبيق.
- تعتمد الإذاعات على توفر مزود البث واتصاله؛ لا يستطيع التطبيق ضمان استمرارية مصدر خارجي أو إصلاح عطل فيه. يحاول استعادة الاتصال تلقائيًا ويترك للمستخدم التحكم في الإيقاف والاستئناف.

## حدود الأمان والنشر

هذا مشروع Frontend ثابت، لذلك لا ينطبق عليه تصميم صلاحيات خادم أو rate limiting أو حماية قواعد بيانات، ولا ينبغي اعتبار العميل حدًا أمنيًا. لا توجد أسرار خادم في الحزمة المقصودة. استخدم HTTPS عند النشر، وطبّق رؤوس الأمن وسياسات الحماية المناسبة على منصة الاستضافة؛ ويجب أن تسمح سياسة CSP بـ`mp3quran.net` ومصادر الصوت والخطوط المستخدمة. لا تضع مفاتيح سرية أو بيانات حساسة في ملفات الواجهة.
