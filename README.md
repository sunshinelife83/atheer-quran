# أثير القرآن

تطبيق ويب ثابت للاستماع إلى إذاعات القرآن الكريم وتصفح مكتبة التلاوات وتنزيل السور للاستماع دون اتصال.

## التشغيل

المشروع يستخدم [Vite](https://vitejs.dev) كخادم تطوير وبناء.

```bash
npm install      # تثبيت الاعتماديات (مرة واحدة)
npm start        # يفتح التطبيق على http://localhost:5173
```

أوامر أخرى:

```bash
npm run dev      # نفس npm start (خادم تطوير مع إعادة تحميل فورية)
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج المبنية
```

ملاحظات:
- في وضع التطوير (`npm start`) يُحمَّل التطبيق فورًا دون تخزين مؤقت، فكل تعديل يظهر مباشرة.
- عامل الخدمة (Service Worker) يُسجَّل تلقائيًا في نسخة الإنتاج فقط (`npm run build` + `preview`) لتمكين العمل دون اتصال.

## الملفات

- `index.html`: هيكل الصفحة (نقطة دخول Vite).
- `styles.css`: تنسيق الواجهة.
- `app.js`: منطق التطبيق وجلب البيانات والتخزين المحلي (يُحمَّل كـ module).
- `public/`: ملفات تُنسخ كما هي (الأيقونة، بيان الويب، عامل الخدمة).
- `vite.config.js` / `package.json`: إعداد خادم التطوير والبناء.

## ملاحظات

- بيانات الإذاعات والقراء تأتي من واجهة `mp3quran.net`.
- التنزيلات تحفظ داخل `IndexedDB` في المتصفح.
- المفضلة وسجل الاستماع يحفظان داخل `localStorage`.
